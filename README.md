# My Personal Website

## What this is
It's a site I made about me and it was actually my first time ever coding in HTML.
## What's on the page
- About: About that tells you about me
- What I'm learning: It goes over stuff I'm learning about
- Contact: It's ways you can contact me
- Background: It's the solar system I coded using JavaScript and hand drawn sprites that actually place the planets based on real life positions using NASAs data
## How I build it
- I used HTML and CSS for the text
- JavaScript for the solar system in the background
- Planet positions come from NASA Horizons data in `planets.json`
## How to open it
- You can open the live site at https://zivzancoeli-commits.github.io/Eli-site/
- Or you can download it from this repo and open it locally
## AI Help
I used an AI assistant to explain how to connect JavaScript and Horizons and to help debug (CORS, git push, scaling). I wrote the HTML/CSS myself with some AI assistance, made the sprites myself, and put the site together in VS Code.
